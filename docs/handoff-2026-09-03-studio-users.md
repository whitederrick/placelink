# PlaceLink Studio 사용자 관리 인수인계 — 2026-09-03

## 결과

- 작업 브랜치: `codex/user-core-qa`
- 사용자 핵심 화면 QA 안정화 이후 Studio 2단계의 사용자 목록·상세를 구현했다.
- 데이터베이스 스키마 변경과 운영 데이터 변경은 없다.

## 구현 내용

- `/{locale}/studio/users`
  - 닉네임, 이메일, 사용자 ID 검색
  - 활성·정지·탈퇴 상태 필터
  - 카카오·구글 가입 경로 필터
  - 최근 활동, 커플 연결, 개인·커플 코스 수와 스크랩 수
  - 커서 기반 페이지네이션
- `/{locale}/studio/users/{id}`
  - 계정과 가입 경로
  - 현재 커플과 구성원
  - 개인·현재 커플 코스 이력
  - 스크랩과 최근 분석 이벤트
- 관리자 전용 읽기 API
  - `GET /api/v1/admin/users`
  - `GET /api/v1/admin/users/{id}`
- Studio 사이드바와 대시보드에서 사용자 관리 화면으로 이동할 수 있다.
- 최근 활동에는 원본 속성이나 임의 개인정보를 표시하지 않고 이벤트명과 시각만
  제공한다.

## 권한과 범위

- 화면과 API는 기존 `ADMIN` 서버 권한 검사를 동일하게 사용한다.
- 이번 구현은 읽기 전용이다.
- 계정 정지·복구·탈퇴 처리와 개인정보 요청 처리는 역할별 권한, 사유 입력,
  감사로그 계약을 먼저 확정한 뒤 구현한다.
