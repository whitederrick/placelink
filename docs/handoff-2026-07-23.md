# PlaceLink 작업 인수인계 — 2026-07-23

## 현재 결과

PlaceLink의 코스 핵심 흐름과 커플 라이프사이클이 실제 DB, Auth.js 세션, SSR/API, 브라우저 UI를 관통하도록 구현·검증되어 있다.

### 코스 흐름

- 앵커 기반 코스 초안 생성
- 주변 장소 추가, 장소별 팁 입력, 동선 저장
- 코스 이름과 소개 입력 후 발행
- 발행된 코스 상세 및 공유용 OG 경로 렌더링
- 스크랩 추가·해제와 마이페이지 저장 목록 반영
- 공유 링크 복사 및 비로그인 공개 URL 접근

### 커플 흐름

- 지훈·민지 개발 계정의 독립 Auth.js 로그인
- 커플 연결 상태와 D-Day 조회
- 초대 링크 생성, 공개 미리보기, 로그인 후 원래 URL 복귀
- 초대 수락과 양쪽 프로필 반영
- 커플 연결 해제와 과거 공동 코스 소유자 익명화
- 만료·사용·취소된 초대, 자기 수락, 동시 수락, 커플 충돌 처리

### 데이터베이스와 마이그레이션

- 로컬 PostGIS 컨테이너는 `localhost:54329`에서 동작한다.
- Prisma shadow DB가 마이그레이션 재생 전에 PostGIS 확장을 생성한다.
- `Place.location` GIST 인덱스와 DB 생성형 위치 필드가 Prisma 스키마와 정렬되어 있다.
- 기존 마이그레이션은 수정하지 않았고 추가 마이그레이션으로 정합성을 맞췄다.

## 이번 진행 내용

- `@playwright/test`와 `pnpm test:e2e` 명령을 추가했다.
- [커플 라이프사이클 E2E](../apps/web/e2e/couple-lifecycle.spec.ts)는 두 브라우저 컨텍스트로 초대·연결·해제를 검증한다.
- [코스 라이프사이클 E2E](../apps/web/e2e/course-lifecycle.spec.ts)는 로그인부터 발행, 스크랩, 공유 URL 접근까지 REG-2 핵심 플로우를 검증한다.
- [공통 자동 픽스처](../apps/web/e2e/test.ts)가 각 테스트 직전에 DB를 시드한다.
- 전역 teardown이 전체 E2E 종료 후 표준 시드 상태를 복원한다.
- Vitest는 `e2e/**`를 제외해 Playwright 스펙과 단위 테스트를 분리한다.

### E2E 과정에서 수정한 문제

- 초대 페이지의 ICU 메시지에 값을 넣기 전에 `next-intl`이 포맷을 시도하던 오류를 `t.raw()`로 수정했다.
- 발행 API는 정상 `200`이지만 개발 서버의 상세 페이지 전환이 기본 대기 시간을 넘을 수 있어, API 성공과 화면 전환을 각각 명시적으로 기다리도록 코스 E2E를 안정화했다.
- 장시간 실행 중인 Next 개발 서버가 새 동적 API 라우트를 반영하지 않은 경우가 있어 서버 재시작 후 라우트 등록을 재검증했다.

## 진행 예정

1. 비어 있는 `.git` 디렉터리의 원래 Git 메타데이터를 복구하거나 원격 저장소에서 안전하게 다시 연결한다.
   - 원래 이력을 덮을 수 있으므로 현재 상태에서 `git init`을 실행하지 않는다.
2. Git 저장소 복구 후 REG-2에 따라 `pnpm test:e2e`를 CI 필수 게이트에 연결한다.
   - 현재 `.github` 워크플로 디렉터리는 없다.
   - CI에서는 PostGIS 서비스, 마이그레이션 적용, Playwright 브라우저 설치가 필요하다.
3. 제품 기준 문서의 단계 2 잔여 항목을 점검하고 다음 제품 백로그를 결정한다.
   - 행동 이벤트 로깅
   - 명예의 전당
   - SEO 완료 기준
   - 홈·피드·필터의 제품 명세 충족 여부
4. 다음 핵심 사용자 흐름을 구현할 때 Playwright 회귀 시나리오를 함께 추가한다.

## 다음 세션 시작 명령

```powershell
docker compose up -d postgres
pnpm db:migrate
pnpm test:e2e
pnpm verify
```

Windows에서 Playwright가 직접 Next 개발 서버를 시작하면 테스트 완료 후 출력 핸들이 늦게 닫힐 수 있다. 로컬 개발 서버가 이미 실행 중이면 Playwright가 이를 재사용해 안정적으로 종료된다.

## 주의 사항

- `.git`은 내용이 비어 있어 현재 디렉터리는 Git 저장소로 인식되지 않는다.
- 사용자 이력을 보존해야 하므로 `git init`, 강제 reset, 기존 파일 삭제를 임의로 수행하지 않는다.
- 단계 5+ 기능인 AI 코스 생성, 예약·결제, 파트너 기능은 ADR 없이 착수하지 않는다.
- 제품 결정은 `docs/place-link_product_baseline.md`, 구현 규칙은 `docs/place-link_development_guide.md`, 구조는 `docs/place-link_architecture_baseline.md`를 우선한다.
