## 알려진 이슈

### `prisma migrate dev`의 PostGIS shadow DB 실패

- 증상: 초기 마이그레이션을 shadow DB에 재적용할 때 `geography` 타입이 없어 `P3006/P3018`로 실패한다.
- 원인: shadow DB에는 초기 마이그레이션 실행 전에 PostGIS extension이 준비되지 않는다.
- 현재 상태: 실제 로컬 DB에는 `prisma migrate deploy`로 모든 마이그레이션을 정상 적용했다.
- 영향: 앱 실행, 테스트, 프로덕션 빌드는 정상이나 새 개발 마이그레이션을 만드는 흐름은 수정이 필요하다.
- 주의: 이미 생성된 마이그레이션 파일을 직접 수정하지 말고 개발환경의 extension 초기화 방식을 정리한다.

### Git 상태 확인

- 현재 Codex 세션에서는 `.git` 디렉터리가 저장소로 인식되지 않아 `git status`와 Turbo dirty hash 조회가 실패했다.
- 작업 파일과 검증에는 영향이 없었지만 다음 세션 시작 시 저장소 메타데이터 상태를 먼저 확인한다.

## 내일 할 일

### 1. 두 계정 실제 E2E 검증 — 최우선

1. A 계정으로 로그인하고 마이페이지에서 시작일과 솔로 코스 전환 여부를 선택한다.
2. 초대 링크를 생성·복사한다.
3. 별도 브라우저 세션의 B 계정으로 링크에 접속하고 로그인 후 수락한다.
4. 양쪽 마이페이지에서 커플명, D-Day, 멤버 이니셜이 동일하게 보이는지 확인한다.
5. A/B 각각의 선택에 따라 솔로 코스가 정확히 전환됐는지 확인한다.
6. 새 코스를 만들었을 때 새 커플 소유로 저장되는지 확인한다.
7. 한쪽에서 연결을 해제하고 양쪽 마이페이지가 솔로 상태로 바뀌는지 확인한다.
8. 기존 공동 코스가 유지되며 `익명 커플 코스`로 표시되는지 확인한다.
