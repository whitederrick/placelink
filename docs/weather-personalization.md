# 홈 시간대·날씨 개인화

## 결정

- 시간대는 서버에서 `Asia/Seoul` 기준으로 아침·오후·저녁·밤을 판정한다.
- 날씨 제공자는 기상청 단기예보 조회서비스의 초단기실황을 사용한다.
- 서울 고정 격자 `nx=60`, `ny=127`만 조회하며 사용자 GPS를 요청·전송·저장하지
  않는다.
- 서버 환경변수 `KMA_SERVICE_KEY`에 공공데이터포털에서 발급받은 일반 인증키를
  설정한다. 인코딩·디코딩 형태 모두 허용한다.

## 화면 계약

- 기상청 응답이 있으면 현재 기온을 표시한다.
- 강수 형태가 비 또는 눈이면 해당 상황에 맞는 코스 안내 문구를 표시한다.
- 초단기실황에는 하늘 상태가 없으므로 강수가 없을 때 `맑음`을 추정하지 않는다.
- 기상청 데이터를 표시할 때 화면에 출처 링크를 함께 표시한다.
- 키가 없거나 조회·파싱·타임아웃이 실패하면 가짜 날씨를 만들지 않고 시간대
  문구만 표시한다.

## 운영 계약

- 기상청 발표 지연을 고려해 현재 시각 40분 전의 정시 실황을 조회한다.
- 같은 서버 프로세스에서는 성공 응답을 10분간 재사용한다.
- 외부 요청은 3초 후 중단하며 홈 피드 데이터베이스 조회와 병렬 실행한다.
- 응답에서 `T1H`(기온)와 `PTY`(강수 형태)만 사용한다.
