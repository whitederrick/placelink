- 작업 브랜치: `codex/multiday-course-planner`
- 목표: 1–3일 코스 플래너를 병합 가능한 상태로 안정화

## 수정한 결함

1. 공개 코스 응답이 장소를 최대 8곳으로 제한해 9–24곳 다일 코스가 상세
   화면에서 실패하던 계약을 최대 24곳으로 수정하고 회귀 테스트를 추가했다.
2. 개발 시드의 행사 기간이 2026년 7월로 고정되어 앵커가 모두 만료되던 문제를
   실행일 기준 7일 전부터 90일 후까지의 결정적 함수로 바꾸고 테스트를 추가했다.
3. 초안 저장과 발행이 동시에 실행될 때 발행된 코스의 노드가 교체될 수 있던 경쟁
   조건을 상태 확인·일정 수정·노드 교체 단일 트랜잭션으로 차단했다.
4. 다일 화면의 날짜·장소 수 문구를 ko/en 번역 키로 통일했다.
5. 앱 빌드 중 DB 마이그레이션을 실행하려던 미커밋 변경은 아키텍처 정본의
   분리 배포 원칙에 맞지 않아 제거했다.

## DB 검증

- 기존 로컬 DB: 7개 마이그레이션 적용 상태와 시드 재실행 확인
- 빈 임시 DB: PostGIS 활성화 후 7개 마이그레이션과 시드 적용 성공
- 시드 결과: 장소 30곳, 현재 활성 앵커 3개, 공개 코스 5개, 코스 노드 15개
- 검증용 DB `placelink_multiday_verify_20260826`은 확인 직후 삭제함

새 DB에는 첫 Prisma 마이그레이션 전에 PostGIS가 활성화되어 있어야 한다. 앱
빌드에서 마이그레이션을 실행하지 않고 Preview 전용 DB 또는 승인된 Production
배포 단계에서 별도로 실행한다.
