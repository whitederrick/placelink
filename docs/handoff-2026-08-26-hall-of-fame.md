# 명예의 전당 주간·월간 집계

## 완료 범위

- 홈 명예의 전당을 최근 7일 주간 순위와 최근 30일 월간 순위로 전환할 수 있다.
- 선택한 집계 기간은 주소의 `ranking` 값과 다음 피드 요청에 유지된다.
- 기간 전환은 `filter.used` 분석 이벤트로 기록된다.
- 한국어와 영어 제목, 선택 버튼, 저장 횟수 문구를 함께 제공한다.

## 집계 기준

- 순위는 공개된 코스의 실제 저장 기록 생성 시각을 기준으로 계산한다.
- 주간은 요청 시점부터 최근 7일, 월간은 최근 30일을 포함한다.
- 운영자가 순위를 직접 고정하는 편집 기능은 운영 정책과 관리자 API가 필요하므로 이번 범위에 포함하지 않았다.

## 확인 결과

- 전체 코드 품질 검사, 형식 검사, 단위검사, 배포 빌드 통과
- 데이터베이스 6개, 웹 59개 단위검사 통과
- 실제 브라우저에서 주간 → 월간 전환 시나리오 통과
