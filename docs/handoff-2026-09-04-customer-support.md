# PlaceLink 사용자 문의·신고 접수 인수인계 — 2026-09-04

## 완료한 작업

- 로그인 사용자가 `/{locale}/support`에서 문의, 불편, 콘텐츠 신고, 개인정보 요청을
  접수할 수 있다.
- 마이페이지에 접수 화면 진입점을 추가했다.
- `POST /api/v1/support-cases`가 접수 건과 최초 `CUSTOMER_MESSAGE`, 감사로그를 한
  트랜잭션으로 저장한다.
- 별도 이메일·연락처를 입력받지 않고 인증된 사용자 ID만 연결한다.
- 제목 120자, 본문 3,000자, 전체 요청 16KB 상한과 위험한 제어문자 차단을 적용했다.
- 사용자별 최근 1시간 접수를 5건으로 제한한다. 기존
  `SupportCase(reporterUserId, createdAt)` 인덱스를 사용하므로 신규 마이그레이션은
  없다.
- 한국어·영어 화면과 390×844 모바일 브라우저 시나리오를 추가했다.

## 검증

- `pnpm verify` 통과
  - Database 테스트 19개
  - Web 테스트 110개
  - 린트, TypeScript, Production 빌드 통과
- 사용자 로그인 → 마이페이지 → 문의 접수 → 관리자 API 확인 Playwright 시나리오 통과

## 현재 제한과 다음 작업

- `STAFF_REPLY`는 아직 실제 이메일·푸시·앱 알림을 발송하지 않는다. 접수 완료
  화면에도 이 제한을 명시했다.
- 사용자에게 과거 접수 목록이나 처리 상태를 보여주는 화면은 아직 없다.
- 요청 빈도 제한은 데이터베이스의 최근 접수 건수를 기준으로 한다. 고동시성에서
  엄격한 원자 제한이 필요해지면 전용 rate-limit 저장소나 원자 카운터로 전환한다.
- 다음 우선순위는 정지 만료 자동 복구 정책과 운영 DB 마이그레이션·Studio 시각
  QA다.
