## 외부 서비스 설정 완료

### Kakao

- 회사 대표 계정으로 새 Kakao 앱을 생성했다.
- 이 앱이 Kakao Map API 일간 무료 쿼터를 받는 앱임을 확인했다.
- JavaScript 키와 REST API 키를 각각 발급했다.
- JavaScript SDK 허용 도메인에 로컬 주소, Vercel 주소, `https://place-link.com`을 등록했다.
- 다음 환경변수에 실제 값을 설정했다.
  - `NEXT_PUBLIC_KAKAO_MAP_APP_KEY`
  - `KAKAO_LOCAL_REST_API_KEY`
  - `AUTH_KAKAO_ID`
  - `AUTH_KAKAO_SECRET`

### Google

- Google Cloud 프로젝트 `PlaceLink`를 생성했다.
- Google Auth Platform의 외부 테스트 앱과 OAuth 클라이언트를 만들었다.
- 테스트 사용자 한 명을 등록했다.
- 다음 환경변수에 실제 값을 설정했다.
  - `AUTH_GOOGLE_ID`
  - `AUTH_GOOGLE_SECRET`
- `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY`는 선택 항목이므로 현재 비워 두었다.

### Auth.js

- `AUTH_SECRET`을 안전한 임의 값으로 생성해 로컬과 Vercel에 설정했다.
- 실제 값은 Git이나 문서에 기록하지 않았다.

## Supabase 운영 데이터베이스

- 기존 Supabase 프로젝트를 사용한다.
- PostGIS 확장이 활성화되어 있음을 확인했다.
- Vercel의 `DATABASE_URL`은 Supabase Session Pooler를 사용하도록 설정했다.
  - 호스트: `aws-1-ap-northeast-2.pooler.supabase.com`
  - 포트: `5432`

- 로컬 `packages/database/.env`는 작업 후 다시 Docker 개발 DB로 복원했다.
  - `localhost:54329`
- 운영 DB에 다음 6개 Prisma 마이그레이션을 적용했다.
  - `20260722050423_init_core`
  - `20260722050500_domain_constraints`

  - `20260722120000_add_couple_invites`
  - `20260722223604_verify_schema_alignment`

## Vercel 배포 진행 상황

환경변수는 Vercel에 등록했다. 이전 실패 원인은 순서대로 다음과 같았다.

1. `DATABASE_URL` 누락
2. `LOG_LEVEL` 값에 따옴표 포함
3. Vercel에서 접근할 수 없는 로컬 Docker DB 주소 사용
4. 운영 DB 마이그레이션 미적용
5. Vercel이 출력 폴더를 `public`으로 잘못 인식
6. 저장소 루트를 Next.js 앱으로 인식하지 못해 `No Next.js version detected`

마지막으로 Vercel 프로젝트 설정을 API를 통해 다음과 같이 교정했고, CLI 조회로 반영을 확인했다.

- Root Directory: `apps/web`
- Framework Preset: `Next.js`
- Build Command: `cd ../.. && pnpm turbo build --filter=@placelink/web`
- Output Directory: `Next.js default`

교정 후 생성된 프로덕션 배포
`placelink-8qcv1nlkw-ahn-namkyus-projects.vercel.app`이 2026-07-28 확인 시
`Ready` 상태였다. 기본 운영 별칭 `placelink-umber.vercel.app`에서 `/ko`와
`/en`은 HTTP 200으로 응답했다.

로컬의 SEO 커밋 두 개가 아직 원격 브랜치에 푸시되지 않아 현재 운영 배포의
`/robots.txt`와 `/sitemap.xml`은 HTTP 404다. `KAKAO_LOCAL_REST_API_KEY`를
`turbo.json`의 `globalEnv`에 추가했다.

대표 도메인 `place-link.com`은 DNS 조회가 되지 않으며 Vercel 계정의 도메인
목록에도 등록되어 있지 않다. 현재 등록된 도메인은 다른 프로젝트의
`able-link.co.kr`, `platforest.com`뿐이다.
