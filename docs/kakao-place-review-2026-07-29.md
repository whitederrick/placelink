# 카카오 장소 후보 검토 — 2026-07-29

## 실행 범위

- 카카오 Local API를 사용해 5개 지역을 각각 `dry-run`으로 조회했다.
- 이 문서의 최초 후보 검토 단계에서는 어떤 DB에도 장소 데이터를 쓰지 않았다.
- 기존 품질 필터(프랜차이즈 카페 제외, 카테고리 일치, 거리순 상위 3개)를 적용했다.

### 성수 동기화 결과

- 사용자 승인 후 개발용 Supabase에 승인 목록 15곳만 동기화했다.
- 결과: 신규 15곳, 갱신 0곳
- 검증: 활성 장소 15곳, Kakao 제공자 참조 15개
- 보류 2곳과 제외 1곳은 DB에 존재하지 않음을 확인했다.
