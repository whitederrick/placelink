# 카카오 장소 후보 검토 — 2026-07-29

## 실행 범위

- 카카오 Local API를 사용해 5개 지역을 각각 `dry-run`으로 조회했다.
- 개발용 Supabase를 포함한 어떤 DB에도 장소 데이터를 쓰지 않았다.
- 기존 품질 필터(프랜차이즈 카페 제외, 카테고리 일치, 거리순 상위 3개)를 적용했다.

## 성수 후보 18곳 최종 검토

### 승인 권고 15곳

| 분류     | 장소                                                |
| -------- | --------------------------------------------------- |
| 전시     | 데어바타테, 포아트 성수                             |
| 카페     | 에낭 성수점, 맥파이앤타이거 성수티룸, 팟리추얼 성수 |
| 숍       | 모나미스토어 성수점, 홈어게인, 사무엘스몰즈         |
| 식당     | 스케줄 성수, 삼선회사랑, 카카모루 성수점            |
| 액티비티 | 서울숲공원산책길                                    |
| 바       | 심심, 브레이크 사일런스, 음악창고 LP BAR            |

### 보류 2곳

| 장소                  | 사유                                                                                         |
| --------------------- | -------------------------------------------------------------------------------------------- |
| 헬로우 아일랜드       | 전시관으로 분류되지만 데이트 코스 적합성과 실제 운영 성격을 한 번 더 확인하는 편이 안전하다. |
| 서울숲 느린산책의정원 | 서울숲공원산책길과 공간 중복 가능성이 있어 별도 장소로 유지할 가치 확인이 필요하다.          |

### 제외 권고 1곳

| 장소                         | 사유                                                             |
| ---------------------------- | ---------------------------------------------------------------- |
| 서울테마산책길 서울숲 공원길 | 서울숲공원산책길과 사실상 같은 동선으로 보여 중복 가능성이 높다. |

성수 승인 권고안은 **15곳 동기화, 2곳 보류, 1곳 제외**다. 사용자 승인 전에는 동기화하지 않는다.
